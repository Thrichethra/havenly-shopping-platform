# Havenly ? Full-Stack E-Commerce Platform

A full-stack online shopping platform specializing in home appliances, built with a **ReactJS** frontend, a **C# ASP.NET Web API** backend, and **Microsoft SQL Server**.

## Key Features
- **Product Catalog & Filtering:** Dynamic product browsing, category filtering, and detailed product views built with ReactJS.
- **Persistent Shopping Cart & Checkout:** Client-side cart state persistence with automated invoice generation logic.
- **RESTful Backend API:** Secure C# ASP.NET controllers (CategoryController, CustomerController, InvoiceController, ProductController) handling product inventory, categories, and order/user requests.
- **Relational Database:** Structured data storage and retrieval powered by Microsoft SQL Server.

## Tech Stack
- **Frontend:** ReactJS, JavaScript (ES6+), CSS
- **Backend:** C# (.NET / ASP.NET Web API)
- **Database:** Microsoft SQL Server
- **Design:** Figma

## Project Structure
- `frontend/` ? ReactJS client application (components, API service layer, styles)
- `backend/` ? C# ASP.NET Web API (Controllers, Models, Data access)
